# Changelog
## 0.3.3 - 2026-10-11
- guia de solução de erros comuns;
- guia de publicação no Git, GitHub Releases e crates.io;
- comandos de package, dry-run, publish, install e yank;
- checklist de publicação e segurança de tokens;
- atualização da tabela consolidada de comandos.
## 0.3.2 - 2026-10-11
- tabela consolidada de comandos Rust;
- referência dos comandos da Origo Overlay;
- tabela de códigos de saída;
- sequências recomendadas de validação, CI e instrumentação;
- novo documento `docs/RUST_COMMANDS.md`.
## 0.3.1 - 2026-10-11
- exemplos executáveis de API básica, análise Rust e integridade SHA-256;
- documentação de uso como dependência local;
- nova referência `docs/RUST_EXAMPLES.md`.
## 0.3.0 - 2026-10-11
- assinaturas Rust multilinhas;
- parâmetros genéricos com vírgulas aninhadas;
- suporte básico a cláusulas where;
- SHA-256 real com RustCrypto;
- canonicalização do host sem blocos Overlay;
- comandos hash e integrity-check;
- testes com vetor SHA-256 conhecido e alteração de conteúdo.

- três testes do adaptador.
## 0.1.0 - 2026-10-11
