# Changelog

## 1.0.0 - 2026-10-11

- finalized the Python reference package and public API;
- added deterministic, domain-separated SHA-256 output;
- added CLI and installable console entry point;
- added selector ambiguity diagnostics;
- added lexical binding normalization for functions, lambdas and comprehensions;
- added 130 conformance vectors;
- covered async comprehensions, generators, yield, yield from and recursion;
- covered decorators, closures, chained calls, mixed arguments and dict literals;
- added CI, release checks, security policy, contribution guide and specification.
